# 🤖 About This Project

This project is a recreation of **BMO**, one of the characters from *Adventure Time*.

The main goal of the project was to recreate BMO's appearance as accurately as possible while learning modern web development tools and version control with Git and GitHub.

Although this repository contains HTML, CSS and JavaScript, the focus of the project was on the design process, customization and implementation rather than writing every line of code from scratch.

---

## 🧠 About the Code

> ⚠️ **The HTML structure of this project was entirely generated with the help of Artificial Intelligence.**

I decided to use AI for generating the initial HTML structure so I could focus on understanding how the code works, customizing it and improving the final result instead of spending time writing repetitive markup.

The project has also been an opportunity to learn how to organize a repository, manage versions with Git and publish projects on GitHub.

---

## 🎨 Design

Unlike the HTML structure, **all BMO facial expressions were designed entirely by me using Figma**.

Each face was recreated manually to resemble the original character while adapting it to the limitations of a web project.

The visual design is therefore one of the most personal parts of this repository.

---

## 🎯 Purpose

This project was created mainly to:

- Practice Git and GitHub.
- Learn the basics of web development.
- Experiment with AI-assisted development.
- Recreate one of my favorite characters from *Adventure Time*.
- Improve my design skills using Figma.
